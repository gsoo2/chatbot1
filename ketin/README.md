# ketin

사진을 찍어야 대화방이 열리는 그룹챗. 하루에 한 번 "케틴"이 울리면 모든 그룹 대화방이 잠기고, 그 그룹에 사진을 올린 사람에게만 다시 열린다.

## 실행

Node 22.5 이상만 있으면 된다. 설치할 패키지가 없다.

```
npm start        # http://localhost:3000
npm test         # 잠금 규칙 확인
```

서버를 켜면 콘솔에 관리자 주소와 키가 나온다. 운영할 때는 환경변수로 직접 정한다.

| 환경변수 | 뜻 | 기본값 |
| --- | --- | --- |
| `PORT` | 포트 | 3000 |
| `DATA_DIR` | DB와 사진이 저장되는 폴더 | `./data` |
| `ADMIN_KEY` | `/admin` 에 들어가는 키 | 첫 실행 때 자동 생성 |

## 규칙

- 케틴 시각은 하루 한 번, 한국 시간 10:00~22:00 사이에 서버가 정한다. 다음 케틴이 울릴 때까지가 한 회차다.
- 그룹 대화방은 이번 회차에 그 그룹에 사진을 올린 멤버에게만 메시지, 사진 파일, 미리보기를 내려준다. 잠금은 서버가 강제한다 (`server.js` 의 `groupView`, `/api/photo`).
- 잠긴 멤버에게는 누가 찍었는지와 안에 쌓인 메시지/사진 개수만 보인다.
- 그룹은 여섯 자리 초대코드로만 들어온다. 오픈채팅은 누구나 참여하고 잠금이 없다.

## 광고

`/admin` 에서 광고를 올리고 끄고 지운다. 자리는 세 곳이다: 홈(그룹 목록), 오픈채팅 목록, 오픈채팅 방 안. 그룹 대화방 안에는 광고가 없다. 자리마다 켜진 광고 중 하나가 무작위로 나가고, 노출 수와 클릭 수가 쌓인다.

## 배포

`DATA_DIR` 이 지워지지 않는 디스크에 있어야 한다. `Dockerfile` 이 들어 있으니 디스크를 붙일 수 있는 곳(Render, Fly.io, 일반 서버 등)에 올리고 `/data` 에 볼륨을 연결한다. 아이폰에서는 Safari로 연 뒤 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 열린다.

## 아직 없는 것

- 푸시 알림 (케틴이 울려도 앱을 열어야 안다)
- 비밀번호/소셜 로그인 (지금은 계정이 기기의 브라우저에 묶여 있다)
- 오픈채팅 신고/차단, 운영자용 메시지 삭제
